# Carbon Accounting Platform

A climate-tech portfolio project inspired by enterprise carbon-accounting platforms such as Watershed, Persefoni, and Sweep.

## Goal

Build a data platform that:

- Ingests business activity data
- Stores raw activity records
- Applies emission factors
- Calculates greenhouse-gas emissions
- Produces auditable carbon reports

## Planned Scope

### Scope 1

Direct emissions:

- Fuel consumption
- Company vehicles

### Scope 2

Indirect energy emissions:

- Electricity consumption
- Heating and cooling

### Scope 3

Supply-chain emissions:

- Business travel
- Purchased goods
- Freight and logistics

## Tech Stack

- Python
- PostgreSQL
- Pandas
- NumPy
- SQLAlchemy

## Project Status

Version 0.1

- Project setup
- Virtual environment
- Repository configuration

## Planned Architecture

Raw Activity Data
→ ETL Pipeline
→ PostgreSQL
→ Emission Factor Engine
→ Carbon Ledger
